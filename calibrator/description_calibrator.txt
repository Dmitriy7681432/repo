1. По can всегда отправляется адрес с уставками ADDR_PRESET_ROM3
2. Фун-я _begin_data_read считывает значение этого параметра, зная can id 034h(52), global - id 2F01h(12033)
3. Фун-я _header_data_read зная read_id 622h(1570), который принимает модуль управления (МУ), отправляет значение этого параметра (адрес начало структур уставок 0xBFD40000) по data_id 654h(1620)
4. Фун-я модуля управления call_read_command_callback принимает этот адрес, считывает с флеш по этому адресу значение и отправляет в can
5. Фун-я _header_data_read принимает этот значение и адрес, далее увеличивает адрес на 4 байта и отправляет снова и так формируется шапка
6. Фун-я main_read_data делает тоже самое, но уже формирует значения уставок
